# Hostel10Euro

Statische Website aus der bestehenden Vorschau. `index.html` ist die Startseite; `preview.html` bleibt erhalten. Kein Build und keine Paketinstallation erforderlich. `.nojekyll` deaktiviert die Jekyll-Verarbeitung.

## GitHub Pages aktivieren

Repository → Settings → Pages → Build and deployment:

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)
- Save

Erwartete Projektadresse nach erfolgreicher Aktivierung: https://arshinfo-bot.github.io/hostel10euro/

Ein eigener Actions-Workflow ist für diese Veröffentlichungsart nicht erforderlich. Den von GitHub gestarteten Pages-Build und den HTTP-Aufruf der Projektadresse nach Aktivierung prüfen.

## Noch offene Veröffentlichungsschritte

- Rechtlichen Betreiber und vollständige Impressumsangaben bestätigen und ergänzen.
- Datenschutzhinweise für tatsächliches Hosting, Kontaktwege und externe Wikimedia-Bilder vervollständigen.
- Bedingungen und Gesamtpreis zum Angebot ab 10 € bestätigen.
- Endfassung durch den Betreiber freigeben; danach Vorschauhinweise und gegebenenfalls noindex entfernen.
- Eigene Domain www.hostel10euro.de erst nach Prüfung der bestehenden DNS-Konfiguration verbinden; anschließend HTTPS prüfen. Noch keine CNAME-Datei gesetzt.
